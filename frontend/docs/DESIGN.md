# Visual system (boing.finance)

> 👋 **Everyday users:** the app uses a stone + engraved-vein + soft neon shell.  
> 🛠️ **Developers:** apply this system consistently — not only on isolated pages.  
> 🛰️ **Operators:** n/a.

Current app chrome is a **stone + engraved-vein + soft neon** shell, not the older aquatic-space `.webp` / canvas engine.

*Last reviewed: August 2026.*

## Shell

| Piece | Role |
|-------|------|
| `frontend/src/components/ColosseumReferenceBackdrop.jsx` | Full-viewport backdrop (respects `prefers-reduced-motion`) |
| `frontend/src/components/AppShellVisualLayer.jsx` | Thin wrapper used from `App.jsx`, Base mini-app, and error boundary |
| `frontend/src/utils/pageVariant.js` | Route → `page-variant-*` class |
| `frontend/src/styles/deep-trade-tokens.css` | Per-page accent emphasis (`trade`, `analytics`, `portfolio`, `governance`, `boing`, `docs`, `landing`) |
| `frontend/src/styles/globals.css` | Design tokens, type, buttons, cards |

`App.jsx` applies `page-landing` on `/` and `page-app` elsewhere, plus `deep-trade-bg page-variant-{variant}`.

## Tokens (canonical in `:root`)

Defined in `globals.css` (dark-first). Current primaries include `--bg-primary: #06080c`, `--accent-teal: #00e5ff`, `--accent-cyan`, `--accent-gold`, `--text-primary`. Prefer these variables over hardcoded hex in components. Recharts should use the same tokens.

## Typography

- **Comfortaa** — body, labels, nav (Google Fonts + local `@font-face` under `frontend/src/assets/fonts/`)
- **Orbitron** — headings (`--font-display`)
- **JetBrains Mono** — addresses / code (`--font-mono`)
- **Cinzel** — optional display serif (`--font-display-serif`)

## Logo & brand rasters

In-app mark is the **rebound medallion SVG in `Logo.jsx`** (custom rounded B, bounce-under trail, cyan orb). Keep geometry in sync with `public/assets/boing-logo-mark.svg`. Comic PNG (`/assets/logo-boing-comic.png`) only when `showComic`. Share / PWA rasters are generated by `frontend/scripts/generate-brand-assets.mjs` (`npm run generate-brand-assets`) and listed in `frontend/src/config/brandAssets.js`. Open Graph uses **`/preview-image.png`**, not a root `og-image.svg`.

## Optional Python assets

`scripts/` can still generate hero/background PNGs into `frontend/public/images/`. Those files are **not** the live app backdrop (Colosseum canvas is). See `scripts/README.md` and `frontend/public/images/README.md`.
