# Optional hero / background source assets

These PNGs are **source material** for the Python scripts in `scripts/` (see `scripts/README.md`). The live app backdrop is **`ColosseumReferenceBackdrop`**, not these files. See [frontend/docs/DESIGN.md](../../docs/DESIGN.md).

Typical filenames (may be gitignored if large):

- `boing_robot_hero.png` — full hero scene
- `hero_optimized.png` / `hero_thumb.png` — from `scripts/enhance_hero.py`
- `boing_background_dark.png` / `boing_background_dark_modified.png` — from `scripts/modify_background.py`
- `hero_elements/` — from `scripts/extract_robot_hero_elements.py`
